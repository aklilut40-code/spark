# Spark

A tiny joke & fact generator — tap a button, get a fresh one. Built as a single HTML file, no dependencies.

🔗 **Live site:** https://aklilut40-code.github.io/spark

## About

Spark shows one joke or fact at a time. Switch between the two with the toggle at the top, tap **Give me another** for a new one, or **Copy** to grab the current one. It won't repeat itself until you've seen everything in that round.

- 20 jokes
- 20 facts

## Tech

- HTML, CSS, and vanilla JavaScript — all in one file
- Hosted for free with [GitHub Pages](https://pages.github.com/)
